# Разработка веб-сервиса коллективной разметки, инспекции и валидации датасетов компьютерного зрения (рабочее название HUB)

## Цель
Создание высокопроизводительной веб-платформы для асинхронной загрузки, векторной разметки, аудита и экспорта визуальных датасетов (Bounding Box, OBB, Polygon) с поддержкой ролевой модели и защиты от конфликтов совместного редактирования

## Результат (продукт)
Веб-приложение с клиент-серверной архитектурой, обеспечивающее полный цикл работы с ML-выборками: загрузка сэмплов, интерактивный векторный редактор масок в браузере, система контроля качества (ревью разметки) и экспорт данных по единому контракту в формате YOLO txt / YAML.

## Критерии приемки

### Технические критерии:
* Клиентский векторный рендеринг: Отрисовка Bounding Box, OBB (повернутые рамки) и Polygon масок через HTML5 Canvas/SVG API без потери FPS браузера на изображениях высокой четкости.
* Поддержка контракта данных: Генерация и считывание .yaml конфигураций классов и экспорт выгрузок единым ZIP-архивом в формате YOLO txt.
* Защита от конфликтов (Soft Lock): Автоматическая блокировка кадра со статусом «В работе у @пользователь» при открытии сэмпла в редакторе для предотвращения перезаписи данных другим участником.
* Аудиторский след (Audit Trail): Сохранение истории изменений (логин автора, дата загрузки, метки времени и создатели каждой маски) с выводом истории в окне инспекции.
* Документация: OpenAPI/Swagger спецификация API бэкенда, Docker Compose для локального развертывания, документация по структуре контракта данных.

### Функциональные критерии:
* Авторизация и профиль: Регистрация/вход по e-mail и паролю + OAuth интеграция (Яндекс ID).
* Галерея и выборки: Поддержка загрузки одиночных файлов и папок, пагинация, быстрые ссылки на сэмплы, переключение вкладок выборок (All, Train, Test, Val) и интерактивный hover-эффект на карточках (исходник / превью с разметкой).
* Ролевая модель: Права доступа внутри датасета: Владелец (управление доступом, экспорт, удаление), Разметчик (редактирование геометрии), Наблюдатель (только просмотр).
* Контур приемки: Смена статусов кадров (Не размечен, В работе, На проверке, Принято, На доработку) с интерфейсом утверждения/отклонения разметки для проверяющего.

## Описание проекта
Проект посвящен разработке инженерного инструментария для подготовки промышленных датасетов компьютерного зрения (Data-Centric AI). Команда реализует высоконагруженную веб-систему для управления визуальными данными и сложным векторным редактированием геометрии объектов прямо в вебе.
